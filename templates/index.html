APIキー設定ガイド
eBay App ID の取得
  1. developer.ebay.com でアカウント作成
  2. 「My Account」→「Application Keys」→ Production の App ID (Client ID) をコピー
  3. .env ファイルの EBAY_APP_ID に貼り付け

過去90日の実売（落札）価格を取得します

Yahoo Japan App ID の取得
  1. developer.yahoo.co.jp でアプリ登録
  2. 「アプリケーション管理」→ クライアントID（Application ID） をコピー
  3. .env ファイルの YAHOO_APP_ID に貼り付け

Yahooショッピングの現在出品価格を参照します

注： ヤフオク落札済み価格の取得にはYahoo Japan OAuth 2.0認証が必要です（将来バージョンで対応予定）。 eBay の実売価格データが最も信頼性の高い相場情報となります。
